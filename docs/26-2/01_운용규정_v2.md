# ICOK Fund 운용규정 v2 (26-2)

> 26-1 복기에서 도출된 규칙 세트. 이 문서는 **누가 무엇을 결정하는가**를 정의한다.
> 26-1 대비 핵심 변경: ① 기계적 로스컷 폐지 ② 중립비중 + 액티브틸트 사이징 도입 ③ 투자위원회 의결제 도입 ④ 지정 매매일제 도입

---

## §1. 원칙

**P1. 중립은 0%가 아니다.**
어떤 종목에 대해 견해가 없으면 벤치마크 내재 비중을 보유한다. 미보유는 "판단 유보"가 아니라 **적극적인 반대 베팅**이다. 26-1의 −8.87%p 중 상당 부분이 "한국주식 랠리 구간 과소보유"에서 나왔고, 이는 견해 없이 취한 액티브 포지션이었다.

**P2. 리스크는 자본이 아니라 리스크로 배분한다.**
26-1에서 자본 41%가 리스크 95.5%를 부담했다. 비중 한도가 아니라 리스크 기여 한도로 관리한다.

**P3. 손실 통제는 진입 시점에 끝난다.**
얼마나 잃을지는 사는 순간 결정된다. 파는 순간이 아니다. 기계적 손절은 사이징 부실을 가려주는 알리바이였으므로 폐지한다.

**P4. 가격은 청산 사유가 아니다. 논리 훼손이 청산 사유다.**
가격 하락은 **재검토를 강제**하는 트리거이지, 매도를 강제하는 트리거가 아니다.

**P5. 목표주가는 하나의 숫자가 아니다.**
모든 투자안은 확률 가중 시나리오로 제출한다. 맞히는 것이 아니라 **틀릴 확률을 정직하게 추정하는 것**이 실력이다.

**P6. 결정과 집행은 분리한다.**
결정은 위원회가, 집행은 트레이더가, 검증은 리스크 오피서가 한다. 세 역할을 한 사람이 겸할 수 없다.

### 2.3 CIO의 권한과 한계 — "최종적으로 사고 파는 사람 너 아니냐"에 대한 답

| 권한 | 내용 |
|---|---|
| 의결권 | **1표.** 다른 위원과 동일. CIO 단독으로 가결 정족수 도달 불가 |
| 거부권 (Veto) | **규정 위반 사유에 한해서만** 행사. 밴드 이탈, 리스크 상한 초과, 문서 미비, 냉각기간 위반. "내 판단과 다르다"는 거부 사유가 될 수 없음. 행사 시 **사유서를 매매로그에 기록** |
| 긴급 집행권 | §2.5에 열거된 상황에 한함 |
| 집행 | **없음.** CIO는 주문을 내지 않는다 |

즉 **CIO는 못 사게 할 수는 있지만, 혼자 사게 할 수는 없다.** 이것이 26-1과의 구조적 차이다.

### 2.4 자금 구조 — 부원이 실제로 굴리는 돈

펀드 NAV를 두 개의 슬리브로 나눈다.

| 슬리브 | 비중 | 운용 주체 | 대상 |
|---|---|---|---|
| **Core** | NAV의 85% | IC | 벤치마크 중립비중 + 승인된 액티브 틸트 |
| **Member** | NAV의 **15%** | 기초 부원 팀 (3~4인 × 4팀) | 승격 심사를 통과한 부원 발제 |

- Member 슬리브는 **실제 자금**이다. 페이퍼가 아니다.
- 팀별 배정: 15%를 4팀에 균등 배분(팀당 NAV 3.75%, 약 130만원). 학기 중 크레딧·프로세스 점수에 따라 재배분.
- Member 슬리브 종목도 §3 사이징 공식과 §4 손실통제 규칙을 **동일하게** 적용받는다. 규칙이 다르면 학습이 안 된다.
- Member 슬리브 종목이 **누적 8주 이상 유지 + 프로세스 점수 상위**이면 승격 심사(W13)를 거쳐 Core로 편입.
- 안전장치: Member 슬리브 전체가 −30%가 되어도 펀드 NAV 영향은 −4.5%. 실험 비용의 상한이 사전에 확정돼 있다.

## §3. 비중조절 체계 — "어떤 체계로 비중조절을 했냐"에 대한 답

### 3.1 Layer 1 — 전략적 자산배분 (SAA)

벤치마크와 동일한 5슬리브. **반기 1회 부원 전체 투표로 확정하며, 학기 중 CIO가 변경할 수 없다.**

| 슬리브 | 목표 | 허용 밴드 |
|---|---|---|
| 한국주식 | 50% | ±10%p (40~60%) |
| 미국주식 | 10% | ±5%p |
| 미국채 | 20% | ±7%p |
| 원자재 | 10% | ±5%p |
| 현금 | 10% | ±7%p |

- 밴드 이탈 시: **밴드 안으로 복구하는 방향의 매매만 허용**. 이탈을 확대하는 매매는 금지.
- 밴드 내에서의 이동은 IC 의결 사항. 밴드 밖으로의 능동적 이동은 **불가**(밴드 자체가 액티브 한도).
- 26-1 대조: 한국주식 54.0% → 17.9%, 스윙 36.1%p, 87일 중 50일 밴드 밖. **이 규칙 하에서는 구조적으로 발생 불가.**

### 3.2 Layer 2 — 리스크 예산

포트폴리오 목표 연환산 변동성 **≤ 25%**, 목표 추적오차(TE) **≤ 12%**.

| 항목 | 상한 | 성격 |
|---|---|---|
| 단일 종목 CRC | 30% | 초과 시 **IC 안건 자동 상정** |
| 단일 클러스터 CRC | 45% | 초과 시 **IC 안건 자동 상정** |
| 단일 종목 액티브 틸트 \|Δw\| | 8%p | **하드 캡** (초과 주문 집행 불가) |
| 액티브 틸트 총합 Σ\|Δw\| | 30%p | **하드 캡** |

> **상한 초과 = 자동 매도가 아니다.** 리스크 오피서가 주간 대시보드에서 초과를 감지하면 다음 IC에 안건이 자동 상정되고, IC는 **2주 내 해소 계획**을 의결한다. 유지를 선택할 수도 있으나 그 경우 사유서를 남긴다.
>
> 26-1에서 SKH CRC가 47%→65%로 오르는 동안 아무 일도 일어나지 않은 것은, 상한이 낮아서가 아니라 **상한 자체가 없어서**였다.

클러스터 정의는 명목 자산군이 아니라 **1년 일별수익률 상관 기준**으로 분류한다(26-1 보고서 방식 계승).
예: KOSPI 대형주 / 글로벌·듀레이션 / 실물·인플레 / 방산·정책.

### 3.3 Layer 3 — 종목 사이징 공식

**보유 비중 = 중립 비중 + 액티브 틸트**

```
w_i  =  w_neutral,i  +  Δw_i

w_neutral,i =  (해당 슬리브 SAA 비중)  ×  (지수 내 시총 비중)
               ※ 지수 편입 종목이 아니면 w_neutral = 0

Δw_i        =  A  ×  (σ_ref / σ_i)  ×  k(컨빅션)  ×  d(상관)
```

| 기호 | 정의 | 값 |
|---|---|---|
| `A` | 액티브 유닛 | **3.0%p** (학기 시작 시 IC가 확정, 학기 중 고정) |
| `σ_i` | 종목 연환산 변동성 | 1년 일별수익률 기준 |
| `σ_ref` | 기준 변동성 | **60%** |
| `k` | 컨빅션 배수 | 컨빅션 5 → 1.6 / 4 → 1.3 / 3 → 1.0 / **2 이하 → 편입 불가** |
| `d` | 상관 할인 | 기존 보유 대비 평균상관 ρ<0.2 → 1.0 / 0.2~0.4 → 0.8 / 0.4~0.6 → **0.6** / ρ>0.6 → **0.45** |

**공식의 의미**

- `σ_ref/σ_i` — 변동성이 크면 작게 담는다. (26-1 ATR 사이징 계승)
- `k` — **26-1에 없던 항.** 확신의 강도가 비중에 반영된다. 그리고 `k`는 회장이 정하지 않고 **IC 무기명 투표의 중앙값**이 정한다.
- `d` — **26-1에 없던 항이자 SKH 문제의 직접적 해법.** 이미 가진 것과 비슷한 것을 새로 사면 크기가 자동으로 깎인다. KOSPI 대형주 상호상관 +0.33~0.50 구간에서 `d = 0.6`이 적용되므로, 26-1처럼 "각각은 적정 사이즈인데 합치면 단일 팩터 몰빵"이 구조적으로 억제된다.

**계산 예시 1 — SK하이닉스 (지수 대형주, 고컨빅션)**
```
w_neutral = 50% × 27.7% = 13.85%
σ = 72.6%,  컨빅션 5 (k=1.6),  기존 보유 대비 ρ ≈ 0.45 (d=0.6)
Δw = 3.0 × (60/72.6) × 1.6 × 0.6 = +2.38%p
w  = 13.85 + 2.38 = 16.2%   ← 목표 비중
```
26-1의 23.3%와 비교하면, **같은 종목·같은 확신에서도 상관 할인 때문에 비중이 7%p 낮게 나온다.**

**계산 예시 2 — 중소형 신규 종목 (지수 미편입, 중간 컨빅션)**
```
w_neutral = 0
σ = 90%,  컨빅션 4 (k=1.3),  ρ ≈ 0.15 (d=1.0)
Δw = 3.0 × (60/90) × 1.3 × 1.0 = +2.60%p
w  = 2.6%
```

**계산 예시 3 — 견해 없음**
```
컨빅션 3 미만 → 편입 불가.  지수 편입 종목이면 w = w_neutral (중립 보유)
```

### 3.4 사이징 공식이 답하는 것

| 대표님 질문 | 26-2의 답 |
|---|---|
| "어떤 체계로 비중조절을 했냐" | 중립비중(지수) + 액티브틸트(변동성·상관·컨빅션의 함수). **공식이 숫자를 낸다.** |
| "네가 만든 리스크 시스템 아니냐" | 공식의 파라미터(A, σ_ref, k·d 구간)는 학기 시작 시 IC가 승인하고 학기 중 고정된다. 유일한 학기 중 변수는 **컨빅션 점수이며, 이는 IC 무기명 투표 중앙값**이다. CIO는 7표 중 1표를 가진다. |

## §4. 손실 통제 — 기계적 로스컷 폐지

**26-1 규칙(폐지):** Trailing MDD NAV −1.0% 축소 / −1.5% 전량 청산, 논리 무관.
**폐지 근거:** 보유종목 연변동성 62~81%(일간 σ ≈ 4~5%). NAV −1.5% 트레일링은 정상 등락에 걸린다. 실증: NAVER 6월 7건 매매 −62만원, 디앤디파마텍 손절 직후 +36% 반등.

대체 규칙은 4단계다.

### 4.1 [진입 시점] 최대손실 사전 확정

발제 시 Bear 시나리오 가격을 명시한다.

```
예상 최대손실(NAV 기여) = w_i × (Bear가격 / 현재가 − 1)
```

- 이 값이 **NAV −1.5%를 초과하면 초과하지 않을 때까지 `w_i`를 축소**한다.
- 즉 26-1의 "−1.5%에서 자른다"가 **"−1.5%를 넘을 수 없게 사는 것"** 으로 이동한다. 통제 시점이 출구에서 입구로 옮겨졌다.

### 4.2 [보유 중] Thesis Tracker — 논리가 손절 사유다

진입 시 발제자는 다음을 문서화한다 (→ [templates/thesis_tracker.md](templates/thesis_tracker.md)).

- **확인 지표 3개** — 논리가 맞다면 나타날 사실 (실적, 수주, 가이던스, 가격, 정책 등 **검증 가능한 사실**)
- **반증 지표 3개** — 논리가 틀렸다면 나타날 사실

> 반증 지표 **2개 이상 확인 시 → 청산 안건 자동 상정.** 주가 수준과 무관.
> 반증 지표는 "주가가 −20% 하락"처럼 가격으로 쓸 수 없다. 반드시 펀더멘털 사실이어야 한다.

### 4.3 [보유 중] Time Stop

- 진입 후 **8주** 경과, 또는 명시한 촉매 이벤트 후 **2주** 경과 시점에 확인 지표가 하나도 충족되지 않으면 → **비중 50% 축소 안건 자동 상정**.
- "논리가 맞는데 시장이 몰라준다"가 반년 이상 지속되는 포지션을 방지한다. 안건일 뿐이므로 IC가 유지를 의결할 수 있다.

### 4.4 [보유 중] Review Trigger — 기계는 리뷰를 강제하고, 판단은 사람이 한다

| 트리거 | 발동 조건 | 의무 |
|---|---|---|
| 종목 드로다운 | 진입가 대비 −20% | 발제자가 **48시간 내 재검토 노트** 제출 |
| NAV 기여 | 단일 종목이 NAV −1.0%p 훼손 | 동일 |
| CRC 초과 | §3.2 상한 초과 | 리스크 오피서가 해소안 제출 |

재검토 노트는 세 가지 중 하나로 결론낸다: **① 논리 유효, 유지 ② 논리 약화, 축소 ③ 논리 훼손, 청산.**
다음 IC에서 표결한다. **자동 매도는 없다.**

> 이것이 "기계적 손절하는 매니저 없다"에 대한 정확한 대안이다. 기계가 하는 일은 **"당신은 지금 이 종목을 다시 봐야 한다"고 강제하는 것**까지이고, 사고 파는 판단은 사람이 근거를 남기고 한다.

### 4.5 [포트폴리오] 서킷브레이커 — 유일하게 남는 기계적 규칙

개별 종목이 아니라 **펀드 생존**에 관한 규칙이므로 기계적으로 운용한다.

| 조건 | 조치 |
|---|---|
| 월중 NAV −8% | 신규 진입 중단, 액티브 틸트 총량 50% 축소 (중립 방향) |
| 학기 누적 NAV −15% | 전 포지션 중립 비중 복귀, IC 전면 재검토 세션 소집 |

26-1 MDD −11.64% 기준으로 보면 1단계는 학기 중 발동 가능성이 있는 수준이며, 이는 의도된 설계다.

## §5. 리서치 규율 — "정답을 찾으려 하지 마라"에 대한 답

### 5.1 단일 목표주가 금지

모든 발제는 3-시나리오 + 확률로 제출한다 (→ [templates/발제_1페이저.md](templates/발제_1페이저.md)).

```
Bull  가격 P_bull,  확률 p1
Base  가격 P_base,  확률 p2
Bear  가격 P_bear,  확률 p3         (p1 + p2 + p3 = 1)

기대수익률 = Σ pᵢ × (Pᵢ/P₀ − 1)
R/R       = (P_bull − P₀) / (P₀ − P_bear)
```

**상정 요건: 기대수익률 > 0 AND R/R ≥ 2.0.** 미달 시 IC 상정 불가.

### 5.2 컨빅션 점수는 "확신"이 아니라 "틀릴 확률"이다

| 점수 | 정의 |
|---|---|
| 5 | 내 Base 시나리오가 **틀릴 확률 ≤ 30%** |
| 4 | 틀릴 확률 ≤ 40% |
| 3 | 틀릴 확률 ≤ 50% |
| 2 이하 | 그 이상 — **편입 불가** |

IC 위원 각자가 무기명으로 1~5를 제출하고 **중앙값**을 채택한다(평균 아님 — 극단값 영향 차단). 이 중앙값이 §3.3의 `k`가 된다.

### 5.3 예측 로그 (Forecast Log)

- 모든 발제의 **Base 시나리오는 3개월 후 자동 검증**된다.
- 학기말에 부원별 **캘리브레이션 리포트**를 낸다: "컨빅션 5로 제출한 건 중 실제 적중률은 몇 %였나?"
- 목표는 적중률 100%가 아니라 **컨빅션 5의 적중률이 실제로 70% 근처인 것**이다. 컨빅션 5의 적중률이 40%면 그 부원은 과신하고 있는 것이고, 90%면 과소평가하고 있는 것이다.
- 부결된 아이디어도 로그에 남기고 동일하게 검증한다. **"안 산 것도 결정"이기 때문이다.**

> 이것이 "주식에 정답 없다"를 말이 아니라 데이터로 체득시키는 유일한 방법이다.
> 부원 평가에서 적중률은 **감점 요소가 아니다.** 캘리브레이션 오차만 본다.

## §6. 매매 규율

### 6.1 지정 매매일제

- 매매는 **매월 둘째·넷째 화요일 정규세션 직후**에만 집행한다. (월 2회)
- 그 외 일자의 집행은 §2.5 긴급 집행권 범위로 한정한다.
- 장중 판단·충동 매매가 **구조적으로 불가능**해진다.
- 26-1 대조: 6월 39건 → 지정 매매일제 하에서는 물리적으로 불가.

### 6.2 회전율 한도

| 항목 | 한도 |
|---|---|
| 월 총 체결 건수 | **12건** |
| 월 신규 편입 종목 | **3종목** |
| 초과 | IC 2/3 특별의결 필요 |

### 6.3 재진입 냉각기간

- 전량 청산한 종목의 **재진입은 30일 후부터** 가능. 예외는 IC 2/3 특별의결.
- 26-1 대조: NAVER 손절 → 당일 재매수 → 재손절 반복(6월 7건, −62만원). **금지.**

### 6.4 매매로그 의무화

모든 체결은 다음을 기록한다: 의결서 번호 / 발제자 / 컨빅션 중앙값 / 산출 목표비중 / 실제 체결비중 / 괴리 사유 / 집행자.
**의결서 번호 없는 체결은 규정 위반**이며, 리스크 오피서가 월간 리포트에 별도 표기한다.
