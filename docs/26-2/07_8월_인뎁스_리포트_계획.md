# 8월 In-depth 리포트 발간 계획

> 기간: **2026.07.29 ~ 08.31** (5주)
> 목적 ① 전 부원 기초체력 (학술·산업·기업) ② TIMEFOLIO IVY Club 카페 활동 공유
> 형식: **대외 3편 (팀) + 개인 리서치 노트 15편**
> 구성: **산업 분석 중심 + Top Pick 1종목 + ICOK Fund 편입 제안**
> 분량: **제한 없음.** 산업 분석에 필요한 만큼 쓴다 (참고: YIG 광 인터커넥트 43p)

## 0. 이 리포트가 남과 달라야 하는 지점

IVY Club 카페는 타 학회가 열람한다. 산업 리포트는 이미 넘치고, 잘 쓰는 곳도 많다.

레퍼런스로 검토한 **YIG 46th「광 인터커넥트」(2026.5.26, 43p)** 는 표지에 이렇게 쓴다.

```
Overweight
Top Pick  성호전자 (043260, KQ)
목표주가 ₩77,400 / 현재주가 ₩41,250 / 상승여력 87.6%
```

**"Overweight"는 정성 표현이다.** 무엇 대비 얼마나 오버웨이트인지, 실제로 얼마를 담겠다는 것인지는 쓰여 있지 않다. 리포트를 쓴 주체가 실제로 굴리는 돈이 없으면 그 이상 쓸 수가 없다.

**ICOK는 쓸 수 있다.** 실제 펀드(72명 투자자), 실제 벤치마크(KRX 300, 8/1 도입), 실제 원장, 실제 성과귀속이 있다.

| 다른 학회 | ICOK |
|---|---|
| "Overweight" | **"벤치마크 내재 비중 3.2%. 우리는 5.5%를 제안한다 (+2.3%p 액티브)"** |
| 목표주가 단일값 | **시나리오별 목표 비중 — Bull이면 7.5%, Bear면 중립 복귀** |
| 리스크 서술 | 기존 포트폴리오와의 실측 상관, 팀 액티브 예산 소진율 |
| — | 정수주 제약 검증 (AUM 2,600만원에서 실제로 몇 주인가) |

**→ 「6. ICOK Fund 편입 제안」을 전 팀 표준 챕터로 넣는다.** 이 챕터가 리포트의 존재 이유다.

부수 효과가 크다. 이 챕터는 **9월 개강 후 그대로 발제 자료가 된다.** 8월 리포트가 26-2 운용의 첫 의결 안건이 되는 구조다.

## 1. 산출물 구조 — 2단 구조

**개인은 완결형 노트를 쓰고, 팀 리포트는 분업한다.** 둘 중 하나만 하면 각각 다른 이유로 실패한다.

| | 분업만 할 때 | 각자 완결만 할 때 |
|---|---|---|
| 문제 | 각자 산업의 한 조각만 보게 되어 **전 과정을 경험하지 못한다** | 4주에 초보가 완결 리포트를 쓰면 **품질이 대외 공개 수준에 못 미친다** |

| 구분 | 편수 | 작성 | 공개 | 분량 |
|---|---|---|---|---|
| **① 개인 리서치 노트** | **15편** | 주니어 각자 담당 기업 1개, **처음부터 끝까지** | **내부** | 5~8p |
| **② 팀 리포트** | **3편** | 팀장 1 + 팀원 5 공저 | **IVY Club 카페 + 통합 사이트** | **35~45p** |

**핵심 연결**: 개인 노트가 팀 리포트의 원재료다. 중복 작업이 아니다.
- 개인 노트의 **산업 파트** → 팀 리포트 §3 밸류체인 세부 분석의 담당 단계
- 개인 노트의 **기업 파트** → 팀 리포트 §5 Top Pick 후보
- 개인 노트의 **편입 의견** → 팀 리포트 §6의 입력값

> **팀 Top Pick = 팀원 개인 노트 중 최고작.**
> 이렇게 하면 선발·유인·무임승차 방지가 한 번에 해결된다. 자기 노트가 팀 리포트의 중심 챕터가 되고, 대외 공개본에 이름이 나간다.

### 팀 리포트 분량 배분 — 산업 분석에 집중한다

| 파트 | 목표 분량 | 비중 |
|---|---|---|
| 산업 분석 (§1~§4) | **20~27p** | **약 60%** |
| Top Pick 기업분석 (§5) | 5~7p | 15% |
| ICOK Fund 편입 제안 (§6) | 4~5p | 12% |
| Exec Summary·결론·부록 | 5~6p | 13% |

기초체력 향상이 목적이므로 **산업 구조와 밸류체인에 지면을 쓴다.** 개별 기업은 Top Pick 1종목만 깊게 다루고, 비교 대상 기업은 필요 시 표로 처리한다.

**작성자 이름을 챕터별로 명기한다.** 각 챕터 끝에 `작성: ○○○`. 대외 공개이므로 자기 이름이 타 학교에 나간다 — 가장 강력한 유인이다.

**품질 하한 처리**: 팀장은 **첨삭하되 대필하지 않는다.** 26-1이 1인 클럽이 된 이유가 회장이 빈칸을 메웠기 때문이다. D-7 중간 점검에서 미달을 조기 발견한다.

## 1-A. 개인 리서치 노트 — 작성 방식

### 왜 완결형인가

기초체력은 **한 기업을 사업모델부터 편입 의견까지 혼자 관통해봐야** 는다. 밸류체인 한 단계만 쓰면 그 단계는 잘 알게 되지만 "그래서 이걸로 돈을 어떻게 버나"에 도달하지 못한다.

그리고 이 노트가 **9월 커버리지 노트와 발제 1페이저의 원형**이다. 8월에 한 번 해본 사람과 안 해본 사람의 차이가 학기 내내 간다.

### 표준 양식 (5~8p)

```
0. 한 문장 요약                                        2~3줄
   "시장은 ○○를 △△로 보지만, 실제로는 □□이며,
    이는 ◇◇(촉매)로 ○개월 내 확인된다"

1. 이 회사는 무엇을 팔아 돈을 버는가                     1p
   · 매출 구성 (제품별·지역별·고객별)
   · 누구에게 파는가 / 가격은 누가 정하는가
   · 최근 3년간 이 구성이 어떻게 바뀌었나

2. 밸류체인 어디에 서 있는가                           1~2p
   · 전방·후방에 누가 있는가
   · 대체 가능한가 — 이 회사가 없으면 무슨 일이 생기나
   · 교섭력의 근거 (기술·점유율·전환비용·규제)
   ★ 이 파트가 팀 리포트 §3의 담당 단계가 된다

3. 숫자                                              1~2p
   · 3개년 매출 / 영업이익 / OPM / OCF / CAPEX / 순차입금
   · 이익을 움직이는 드라이버 2~3개를 특정
   · 그 드라이버가 최근 어느 방향으로 가고 있나

4. 밸류에이션                                          1p
   · 5년 배수 밴드 (PER·PBR·EV/EBITDA 중 이 업종에 맞는 것)
   · 현재 위치 + 피어 비교
   · 가정을 반드시 명시 — "무엇을 전제로 이 배수가 정당한가"

5. 시나리오                                            1p
   · Bull / Base / Bear 목표가 + 확률 (합 100%)
   · 각 시나리오의 전제를 한 줄씩
   · 기대수익률과 R/R

6. 내가 틀렸다면 무엇이 먼저 보이나                     0.5p
   · 반증 지표 3개 — 검증 가능한 사실로만. 주가는 쓸 수 없다

7. 편입 의견                                          0.5p
   · KRX 300 내 이 종목의 비중 (= 중립)
   · 제안 비중과 이유
   · 1주가 팀 슬리브에서 몇 %인가 (정수주 검증)

부록  자료 출처 일람
```

### 작성 규율 3가지

**① 자료 위계를 지킨다**

| 순위 | 자료 | 용도 |
|---|---|---|
| 1 | **사업보고서·IR자료·컨퍼런스콜** | 논지의 근거 |
| 2 | 산업협회 통계·정부 데이터 | 시장 규모·점유율 |
| 3 | 증권사 리포트 | **참고만.** 인용 시 출처 명기 |
| 4 | 뉴스 | 사실 확인용 |

> **증권사 리포트를 논지의 근거로 쓰지 않는다. 그것은 남의 논지다.**
> 학회 리포트가 실패하는 가장 흔한 방식이 증권사 리포트 3편을 요약해 붙이는 것이다. 그렇게 쓰면 기초체력이 늘지 않고, 읽는 사람도 안다.
> **최소 요건: DART 사업보고서를 직접 열어 최소 1회 통독한다.**

**② 모든 숫자에 출처와 기준일을 단다**
표 하나에 `출처: DART 2025 사업보고서, 2026.03` 형태로. 예외 없다.

**③ 형용사를 금지한다**
"유망하다·성장성이 크다·저평가되어 있다"는 쓰지 않는다. 대신 **숫자와 반증 가능한 문장**으로 쓴다.
- ✗ "동사는 압도적 기술력을 보유"
- ○ "1.6T 이상 글로벌 점유율 75~80% (출처: ○○, 2026.05)"

### 제출·첨삭 흐름

| 시점 | 제출 | 첨삭 |
|---|---|---|
| W0 | 1p 아웃라인 (무엇을 쓸 것인가 + 자료 출처 3개) | 팀장 |
| W1 | §1~2 초안 (사업모델·밸류체인) | 팀장, 3일 내 반환 |
| W2 | §3~4 (숫자·밸류에이션) | 팀장 |
| W3 | §5~7 완성 + 전체 통합 | 팀장 + 교차 팀 |
| W4 | 최종본 | — |

**팀장 첨삭은 "사실 오류와 출처 누락"만 본다.** 문장을 고쳐주지 않는다. 고쳐주기 시작하면 팀장이 15편을 다 쓰게 된다.

## 2. 주제 선정 기준

**「6. 편입 제안」을 쓸 수 있는 산업인가** — 기준은 이것 하나다.

즉 ① KRX 300 안에 그 산업이 의미 있는 비중으로 존재하고, ② 우리가 실제로 담을 만한 Top Pick이 있어야 한다. 벤치마크에 없는 산업을 다루면 편입 제안이 "0%에서 시작하는 순수 베팅"이 되어 논의가 빈약해진다.

## 3. 표준 목차 (전 팀 동일)

목차를 W0에 확정하지 않으면 4주 내내 각자 딴 얘기를 쓴다. **템플릿은 협상 대상이 아니다.**

### 표지

```
[섹터 투자의견]  Overweight / Neutral / Underweight
[Top Pick]      종목명 (코드, 시장)
                투자의견 · 목표주가 · 현재가 · 상승여력 · 기준일
★ [제안 편입비중]  벤치마크 X.X%  →  제안 Y.Y%  (액티브 +Z.Z%p)
```

### 6.1 벤치마크 내 이 산업의 위치

### 6.2 중립 대비 액티브 판단

§1~§4 산업 분석의 결론이 여기로 수렴한다.

```

액티브 틸트의 근거는 산업 분석에서 나온 것이어야 하며,
"좋아 보인다"가 아니라 "컨센서스와 무엇이 다른가"로 서술한다.
```

| 팀 액티브 예산 대비 소진율 | ZZ% (예산 ±6%p 기준) |

### 6.4 ★ 시나리오별 비중 조절

**가장 중요한 절이다. 그리고 가장 틀리기 쉬운 절이다.**

> **원칙: 시나리오는 주가 수준이 아니라 "사실의 상태"로 정의한다.**
>
> "주가가 −20% 빠지면 비중을 줄인다"는 것은 26-1의 기계적 로스컷이며, 우리는 그것을 폐기했다.
> 대표님 지적대로 **기계적 손절을 하는 매니저는 없다.** 시나리오 전환 트리거는 **검증 가능한 사실**이어야 한다.

**① 시나리오 정의와 목표 비중**

| 시나리오 | 확률 | 12M 목표가 | 상승여력 | **목표 비중** | 액티브 틸트 | **전환 트리거 (사실)** |
|---|---|---|---|---|---|---|
| **Bull** | %  | 원 | % | % | +%p | 예: 수주잔고 3분기 연속 컨센 상회 |
| **Base** | %  | 원 | % | % | +%p | 현 상태 유지 |
| **Bear** | %  | 원 | % | 중립 복귀 | 0%p | 예: 주력 고객사 CAPEX 가이던스 하향 |
| **합** | **100%** | | | | | |

```
기대수익률 = Σ pᵢ × (Pᵢ/P₀ − 1)
R/R        = (P_bull − P₀) / (P₀ − P_bear)      ← 2.0 미만이면 편입 제안 불가
```

**② 주가 경로 × 논리 상태 매트릭스** ★

시나리오가 바뀌지 않은 상태에서 주가만 움직였을 때 어떻게 할 것인가. **여기서 매니저의 사고가 드러난다.**

| | **논리 유효** (확인지표 충족) | **논리 훼손** (반증지표 발생) |
|---|---|---|
| **주가 상승** | 목표가 근접 → **단계적 축소** (밸류에이션 부담, 기대수익률 하락) | **즉시 중립 복귀** |
| **주가 하락** | 기대수익률 상승 → **비중 확대** | **청산** |

> **논리가 유효한데 주가가 빠지면 비중을 늘린다.** 이것이 26-1과의 결정적 차이다.
> 26-1에서는 디앤디파마텍을 손절했고 직후 +36% 반등했다. 논리가 아니라 가격이 매도를 결정했기 때문이다.
> 반대로 논리가 훼손됐는데 주가가 버티고 있으면 그때가 파는 시점이다.

**③ 확인 지표 / 반증 지표**

| 구분 | 지표 | 확인 방법 | 확인 시점 |
|---|---|---|---|
| 확인 1 | | | |
| 확인 2 | | | |
| 확인 3 | | | |
| 반증 1 | | | |
| 반증 2 | | | |
| 반증 3 | | | |

> **반증 지표에 주가를 쓸 수 없다.** "−20% 하락"은 반증이 아니라 재검토 트리거다.
> 반증 지표 2개 이상 확인 시 청산 안건이 자동 상정된다.

### 6.5 정수주 제약 검증

AUM 2,600만원에서 **제안 비중이 실제로 실현 가능한지** 검증한다.

| 항목 | 값 |
|---|---|
| 제안 비중 | Y.Y% |
| 금액 환산 | 원 |
| 현재가 | 원 |
| 필요 주수 | 주 |
| **1주가 NAV에서 차지하는 비중** | %p |
| 판정 | 자유 사이징 (1주 < NAV 3%) / 팀 ±1주 (3~6%) / **팀 틸트 불가** (> 6%) |
| 반올림 후 실현 비중 | % (제안 대비 ±%p) |

> 7/27 기준 KRX 300에서 **효성중공업은 1주가 NAV의 10.10%**인데 벤치마크 비중은 0.45%다. 1주만 사도 +9.64%p 틸트로 하드캡을 넘어 **매수 자체가 불가능**하다.
