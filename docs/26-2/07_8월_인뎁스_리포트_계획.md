## 0. 이 리포트가 남과 달라야 하는 지점

IVY Club 카페는 타 학회가 열람한다. 산업 리포트는 이미 넘친다. **ICOK만 쓸 수 있는 것은 하나뿐이다.**

| 다른 학회 | ICOK |
|---|---|
| "이 산업 좋아 보입니다" | **"우리가 실제로 샀고, 이만큼 벌고 잃었습니다"** |
| 추정 밸류에이션 | 실제 체결가·실제 손익·실제 성과기여 |
| 리스크 서술 | 보유 종목 실측 변동성·상관·CRC |
| 성공 사례 | **실패 기록 공개** (거의 아무도 안 한다) |

26-1 자산이 이미 있다.

| 자산 | 내용 |
|---|---|
| 거래원장 | 94건 (3~6월 88건), 체결가·수량·일자 |
| 종목별 확정손익 | 29종목, 실현 + 6/30 평가 |
| 월별 성과기여 | 좌당 MTM 기준, 종목별 %p |
| 리스크 실측 | 10종목 1년 일별수익률 기반 CRC·상관행렬 |
| 벤치마크 실측 | KRX 300 구성종목 300개 (2026-07-27) |

**→ 모든 팀 리포트에 「ICOK Fund 실전 기록」 챕터를 표준으로 넣는다.** (§3 목차 5번)

## 1. 산출물 구조

| 구분 | 편수 | 작성 | 공개 | 분량 |
|---|---|---|---|---|
| **팀 리포트** | 4편 | 시니어 1 + 주니어 3~4 공저 | **IVY Club 카페 + 통합 사이트** | 15~20p |
| 개인 파트 | 19편 | 각자 1파트 | 팀 리포트의 챕터로 흡수 | 2~3p |

**개인 파트에 작성자 이름을 명기한다.** 각 챕터 끝에 `작성: ○○○`. 대외 공개이므로 자기 이름이 타 학교에 나간다 — 이것이 가장 강력한 유인이다.

**품질 하한 처리**: 시니어는 **첨삭하되 대필하지 않는다.** 26-1이 1인 클럽이 된 이유가 회장이 빈칸을 메웠기 때문이다. D-7 중간 점검에서 미달을 조기 발견하고, 그래도 미달이면 해당 파트를 축약해 싣되 저자명은 유지한다.

## 2. 주제 선정 — 26-1 실전 데이터가 있는 산업

「실전 기록」 챕터를 쓰려면 **그 섹터에 26-1 매매 기록이 있어야 한다.** 26-1 종목별 확정손익 기준 후보:

| 후보 산업 | 26-1 실전 데이터 | 소재 강도 |
|---|---|---|
| **반도체·메모리** ★ | SKH **+751만** (학기 기여 +12.91%p, 매매 8건) · 삼성전기 +36 · 코스텍시스 −39 | 최상 — 최대 성공이자 최대 집중 실패가 같은 종목 |
| **조선·방산** ★ | 삼성중공업 +46 · 한화엔진 +11 · LIG넥스원 −43 · 한화오션 −46 | 최상 — **같은 섹터 4종목이 정확히 반반 갈렸다.** "왜 갈렸나"가 곧 리포트 논지 |
| **전력기기·에너지 인프라** ★ | LS ELECTRIC −28 | 중 — 데이터는 얇으나 KRX300 내 비중 큼(LS ELEC 0.56% + HD현대일렉 0.53% + 효성중공업 0.45%), AI 전력수요 테마 |
| **바이오·헬스케어** ★ | 디앤디파마텍 **−76만** (최대 손실, **손절 직후 +36% 반등**) | 상 — 단일 종목이나 교훈이 강렬. 기계적 로스컷 폐지의 실증 |
| 로봇·자동차 | 로보티즈 +25 · 현대모비스 −22 · 현대차 −35 | 중 |
| 플랫폼·SW | NAVER **−62만** (6월 7건 휩쏘) · LG씨엔에스 −36 | 중 — 행동재무 소재로는 강함 |
| 소재·2차전지 | 삼성SDI +49 · 효성티앤씨 −28 | 중 |

**권장 4편**: 반도체·메모리 / 조선·방산 / 전력기기·에너지 인프라 / 바이오·헬스케어

- 앞의 둘은 실전 데이터가 압도적이다.
- 전력기기는 26-2 유니버스에서 비중이 크고 현재 시장 테마다.
- 바이오는 "손절 직후 +36% 반등"이라는 기록이 있어 실전 챕터가 가장 정직하고 화제성이 있다.

> 팀별 관심에 따라 교체 가능하되, **선정 기준은 하나다 — 「실전 기록」 챕터를 쓸 데이터가 있는가.** 없으면 그 리포트는 다른 학회 것과 구분되지 않는다.

## 5. 품질 장치 — 3단 검수

대외 공개물이므로 검수 단계를 명시한다. **각 단계가 보는 것이 다르다.**

| 단계 | 주체 | 보는 것 | 시점 |
|---|---|---|---|
| 1차 | 시니어 (팀 내) | **사실 오류·출처 누락** | W1, W2 |
| 2차 | 교차 팀 | **논리 비약·근거 부족** | W3 |
| 3차 | CIO | **과장된 주장·검증 불가 서술** | W4 |
| 편집 | 에디터 | 표기·단위·차트·레이아웃 | W4 |

### 대외 공개 전 체크리스트

- [ ] 모든 숫자에 출처와 기준일이 있는가
- [ ] "좋다·유망하다·성장한다" 같은 검증 불가 표현이 남아 있는가
- [ ] 논지가 **반증 가능한 문장**으로 쓰였는가
- [ ] 컨센서스와 우리 견해의 차이가 명시됐는가
- [ ] 실전 기록의 숫자가 26-1 운용보고서와 정합하는가
- [ ] **실패 기록을 축소하지 않았는가**
- [ ] 작성자명이 챕터별로 표기됐는가
- [ ] 목표주가가 단일값이 아니라 시나리오+확률로 제시됐는가

> 마지막 두 항목이 ICOK 리포트의 서명이다. 실패를 그대로 쓰고, 하나의 정답을 제시하지 않는다.

## 7. 이 계획이 9월로 이어지는 지점

8월은 독립 이벤트가 아니라 26-2 커리큘럼의 선행 학습이다.

| 8월에 한 것 | 9월에 이어지는 곳 |
|---|---|
| 표준 목차로 리포트 작성 | W7 1페이저 (같은 사고 구조의 축약판) |
| 산업 밸류체인 매핑 | W6 산업분석 세션 |
| 재무·밸류에이션 시트 | W2~W5 학술 기초 |
| 교차 팀 리뷰 | 레드팀 제도 |
| 시니어의 첨삭·강의 | 시니어-주니어 도제 구조 |
| 담당 섹터·기업 숙지 | **커버리지 종목 배정** — 8월에 쓴 기업이 자기 커버리지가 된다 |
| 실전 기록 작성 | W12 행동재무 (26-1 매매 해부) |

**특히 마지막에서 두 번째가 중요하다.** 8월에 자기가 판 기업이 9월 커버리지 종목이 되면, 학기 시작 시점의 출발선이 완전히 달라진다.
