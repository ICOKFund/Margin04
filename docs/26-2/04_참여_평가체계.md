# 26-2 참여 · 평가 체계

> 참여율은 독려로 오르지 않는다. **산출물이 실제 자금에 연결되는 경로**가 있을 때만 오른다.
> 이 문서는 그 경로와, 그것을 측정하는 방법을 정의한다.

---

## 1. 참여 설계의 3층 구조

```
Layer 3  ── 팀의 재량이 넓어진다 ─────────  액티브 예산 재배분 (W8 · W16)
              ↑ IR 35 / 프로세스 40 / 캘리브레이션 15 / 밴드준수 10
Layer 2  ── 실제 자금이 움직인다 ─────────  팀 맨데이트 슬리브 (NAV 20~30%)
              ↑ 팀 미니 IC 의결 → 노셔널 북 → 넷팅 집행
Layer 1  ── 매주 산출물을 낸다  ──────────  커버리지 노트 · 레드팀 · 대시보드
```

각 층에 **진입 가능한 최소 노력**이 정의돼 있어야 한다. 기초 부원이 Layer 1에서 시작해 학기 내에 Layer 3까지 갈 수 있는 경로가 보이면 참여한다. 26-1에는 Layer 1만 있었고, 그 위가 회장 혼자였다.

> Layer 3의 보상이 **자본이 아니라 재량**인 것이 핵심이다. 자본을 성과로 옮기면 펀드의 자산배분이 성과 추종으로 흔들리고, 그것이 26-1의 실패를 조직 규칙으로 재현한다. ([05_멀티매니저_구조.md](05_멀티매니저_구조.md) §6.2)

## 2. ICOK 크레딧

주간 산출물과 세션 기여를 점수화한다. 크레딧은 **다음 학기 리스크 예산 배정권**으로 환산된다.

### 2.1 획득

| 활동 | 크레딧 | 비고 |
|---|---|---|
| 커버리지 노트 제출 (주간) | 2 | 미제출 0, 지각 1 |
| 세션 구두 업데이트 (월 1회) | 3 | |
| 실적 리뷰 노트 | 4 | 실적 시즌 |
| **정식 발제 (IC 상정)** | **10** | 부결돼도 동일 지급 |
| **레드팀 반박 노트** | **5** | |
| 월간보고서 챕터 작성 | 8 | 마감 준수 시 +2 |
| 리스크 대시보드 생산 (주간) | 4 | 리스크 오피서 |
| 매매 집행 + 로그 관리 | 3 | 트레이더 |
| NAV·성과기여 산출 | 4 | 퍼포먼스 |
| In-depth 리포트 공저 | 12 | 팀 분배 |
| Thesis Tracker 갱신 (월) | 3 | 보유 종목 있는 경우 |
| Review Trigger 48h 내 대응 | 5 | **지연 시 −5** |
| 캘리브레이션 상위 3인 | 10 | 학기 1회 |

### 2.2 감점

| 항목 | 크레딧 |
|---|---|
| 커버리지 노트 무단 미제출 | −2 |
| 보고서 챕터 마감 초과 | −4 |
| Review Trigger 48h 초과 | −5 |
| 의결서 없는 체결 (트레이더) | −10 |
| 냉각기간·밴드 위반 매매 | −10 |

> **부결된 발제는 감점하지 않는다.** 감점하면 아무도 발제하지 않는다.
> **틀린 예측도 감점하지 않는다.** 캘리브레이션 오차만 본다(§4).

### 2.3 크레딧의 용도 — 여기가 핵심

크레딧은 상장이 아니라 **자본 배분권**이다.

| 용도 | 내용 |
|---|---|
| 팀 액티브 예산 재배분 (W8·W16) | 팀 크레딧 합계가 프로세스 점수(40점)의 주 구성요소 |
| IC 로테이션 위원 선정 | 전월 크레딧 1위 자동 지명 (+ 추첨 1인) |
| 27-1 역할 배정 | PM·리스크 오피서 우선 지명권 |
| 27-1 개인 리스크 예산 | 크레딧 상위 부원에게 개인 명의 액티브 유닛 배정 (파일럿) |

> 크레딧이 "성실상"에 그치면 아무도 신경 쓰지 않는다. **더 큰 돈을 굴릴 권리**여야 작동한다.

## 3. 평가 = 프로세스 70 : 결과 30

한 학기(4개월, 약 80거래일) 수익률은 통계적으로 실력을 구분하지 못한다. 26-1이 증거다 — 학기 기여 +8.66%p 중 SKH 한 종목이 +12.91%p였다. 수익률로 평가하면 그해 SKH를 산 사람이 최고 실력자가 되고, 그건 **"정답 찾기"를 조직 차원에서 장려하는 것**이다.

### 3.1 프로세스 점수 (70점)

| 항목 | 배점 | 측정 |
|---|---|---|
| 사전 문서화 | 20 | 시나리오 3종·확률·R/R·Thesis Tracker 완비율 |
| 대응 적시성 | 15 | Review Trigger / Time Stop 대응 48h 준수율 |
| 규정 준수 | 15 | 밴드·CRC 상한·냉각기간·매매 건수 위반 0건 |
| 산출물 제출률 | 10 | 커버리지 노트 + 챕터 마감 |
| 레드팀 기여 | 10 | 반박 노트 품질 (PM 평가) |

### 3.2 결과 점수 (30점)

| 항목 | 배점 | 측정 |
|---|---|---|
| 캘리브레이션 | 15 | 컨빅션 대비 실제 적중률 오차 (§4) |
| 기여도 | 10 | 담당 종목의 **맨데이트 BM 대비 초과 기여** |
| 팀 IR | 5 | 팀 슬리브의 맨데이트 BM 대비 정보비율 |

> 개인·팀 모두 **절대 수익률로 평가하지 않는다.** 채권 맨데이트 팀과 코스닥 중소형 맨데이트 팀을 절대수익률로 비교하면 σ가 4배 큰 쪽이 실력과 무관하게 이긴다. 26-1 실증: 채권·원자재 슬리브 학기 손익 합계 +35만원 vs SKH 단독 +751만원.

> 캘리브레이션(15)이 절대 기여도(10)보다 배점이 높다. **의도적이다.**
> "얼마나 벌었나"보다 "자기가 얼마나 아는지 정확히 아는가"를 더 높게 친다.

## 4. 캘리브레이션 측정 — "정답은 없다"를 데이터로 가르치기

### 4.1 측정 대상

| 소스 | 내용 |
|---|---|
| 발제 컨빅션 점수 | 컨빅션 5로 제출한 건들의 3개월 후 Base 시나리오 실현율 |
| W11 예측 10문항 | 확률 명시 예측의 실현 여부 |
| IC 투표 기록 | 각 위원의 무기명 투표 → 학기말 개인별 복원 후 채점 |

### 4.2 채점 방식 (Brier Score)

```
Brier = (1/N) × Σ (예측확률 − 실제결과)²        실제결과: 발생 1, 미발생 0
```
- 0에 가까울수록 좋다. 0.25 = 무작정 50%로 찍은 것과 동일.
- **적중률이 아니라 Brier가 점수다.** 90%라고 하고 맞히는 것보다, 60%라고 하고 60% 맞히는 게 낫다.

### 4.3 학기말 리포트에 공개하는 것

| 지표 | 의미 |
|---|---|
| 개인별 캘리브레이션 곡선 | 예측확률 구간별 실제 실현율 |
| 과신 지수 | (평균 예측확률 − 실제 적중률). 양수면 과신 |
| 컨빅션 5 실현율 | 규정상 정의는 "틀릴 확률 ≤30%" → **70% 근처가 정상** |
| IC 전체 vs 개인 | 위원회 중앙값이 개인 최고점수보다 나았는가 |

> 마지막 항목이 중요하다. **IC 중앙값이 개인보다 잘 맞았다는 것이 데이터로 확인되면, 합의체 의사결정의 정당성이 회장의 주장이 아니라 사실이 된다.** 반대 결과가 나오면 규정을 고쳐야 한다.

## 5. 참여율 KPI (회장의 실제 KPI)

CIO 평가는 펀드 수익률이 아니다. 다음이다.

| KPI | 26-1 실적 | 26-2 목표 |
|---|---|---|
| 주간 산출물 제출률 | 측정 안 됨 | **≥ 85%** |
| 발제 건수 | 사실상 회장 단독 | **≥ 19건 (전원 1건 이상)** |
| 보고서 챕터 중 회장 작성 비중 | 100% | **≤ 25%** |
| IC 의결 없는 체결 건수 | 88건 (전량) | **0건** |
| 리스크 대시보드 부원 생산 횟수 | 0 | **15회** |
| CRC를 직접 계산해본 부원 수 | 1명 | **19명 (W9)** |
| 학기 중도 이탈 | — | **≤ 2명** |
| 규정 위반 건수 | 규정 부재 | 공개하되 목표 설정 안 함 (은폐 방지) |

마지막 줄에 주의. **위반 건수 0을 목표로 잡으면 은폐가 발생한다.** 위반은 전부 공개하되 목표치를 두지 않고, 대신 "위반 후 시정 완료 기간"을 관리한다.

## 6. 실패 시나리오와 대응

조직화는 반드시 품질 하락 구간을 지난다. 미리 정해둔다.

| 시나리오 | 발생 신호 | 사전 대응 |
|---|---|---|
| 부원 산출물 품질이 너무 낮아 IC 상정이 불가 | W7 1페이저 4건 중 3건 이상 부결 | 부결 사유를 5개 항목 체크리스트로 공개 → W8~W9에 재제출 기회. **회장이 대신 쓰지 않는다.** |
| 팀 슬리브 손실 확대 | 맨데이트 BM 대비 −15%p | 해당 팀 액티브 예산 50% 축소 + 중립 복귀. 팀 해체·자본 회수 아님 — 복기 세션 1회 |
| 4팀이 같은 종목으로 몰림 | 합산 CRC 30% 초과 | 오버레이 비례 삭감. 삭감 비용을 몰린 팀들이 어트리뷰션으로 부담 |
| 분기 재배분이 운 대회가 됨 | 재배분 결과가 직전 분기 절대수익률 순위와 일치 | W13 어트리뷰션 해부에서 베타/알파 분해 공개. IR 배점 35 유지, 절대수익률 배점 **0** |
| 참여율 급락 | 제출률 2주 연속 <60% | 커버리지 노트를 격주로 완화, 대신 세션 구두 업데이트 강화 |
| IC 의결이 형식화 (전원 찬성 반복) | 3회 연속 만장일치 | 레드팀 반대표 의무화 — 레드팀은 반드시 반대표 또는 컨빅션 3 이하 제출 |
| 회장이 다시 다 하게 됨 | 보고서 회장 작성 비중 >50% | **미제출 챕터는 공란으로 발간.** 이 규칙만은 예외 없이 |

마지막 항목이 전부다. 26-1이 1인 클럽이 된 이유는 회장의 역량이 아니라, **빈칸을 회장이 메웠기 때문**이다.

## 7. 홈커밍 발표 개선 (26-2 말)

"내용이 너무 어렵다"는 피드백에 대한 대응은 **내용을 쉽게 만드는 것이 아니라 발표 주체를 바꾸는 것**이다.

| 26-1 | 26-2 |
|---|---|
| 회장 1인 발표 | **부원 4~5인 릴레이 발표** (팀별 In-depth 요약 + 리스크 오피서의 CRC 설명) |
| CRC·상관행렬 원본 슬라이드 | 부원이 직접 계산한 과정을 보여주는 슬라이드 |
| 성과 중심 | **프로세스·규정 준수 현황 → 성과** 순서 |
| 결론: "26-2에 규칙으로 바꾸겠습니다" | 결론: "바꾼 규칙이 이렇게 작동했습니다" (준수율 데이터) |

CRC를 이해 못 하는 선배에게 필요한 건 쉬운 CRC가 아니라, **1학년 부원이 그걸 설명하는 장면**이다.
