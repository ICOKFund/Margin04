## 5. 사이징 산출 (운용규정 §3.3)

| 항목 | 값 | 산출 |
|---|---|---|
| 지수 내 시총 비중 | % | |

| σ_i (연환산, 1년) | % | |
| σ_ref | 60% | 고정 |
| 기존 보유 대비 평균 상관 ρ | | 리스크 오피서 제공 |
| **d (상관 할인)** | | ρ<0.2→1.0 / 0.2–0.4→0.8 / 0.4–0.6→0.6 / >0.6→0.45 |
| A (액티브 유닛) | 3.0%p | 고정 |
